# Файловий менеджер  — Лабораторна робота №4
## Задоєнко Роман  ІПЗ-24-3  

##  Як запустити
1. Встановити залежності: `npm install`.
2. Запустити проект через Expo: `npx expo start`.
3. Відсканувати QR-код у додатку **Expo Go** на смартфоні.

##  Що вміє програма 
* **Навігація:** Можна ходити по папках та повертатися назад (кнопка "Вгору").
* **Робота з файлами:** Створення нових папок та `.txt` файлів з початковим вмістом.
* **Редагування:** Можна відкрити будь-який текстовий файл, змінити текст і зберегти його.
* **Видалення:** Видалення непотрібних об'єктів з підтвердженням.
* **Інфо:** Перегляд розміру, типу та дати останньої зміни файлу.
* **Пам'ять:** На головному екрані завжди видно, скільки ГБ вільно та зайнято на пристрої.
