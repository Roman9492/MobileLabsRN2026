Інструкція із запуску:
Відкрив термінал у папці проєкту.
Ввів команду: npx expo start --tunnel
Відсканував QR-код камерою телефону

Опис основних способів запуску мобільного додатка
На телефоні:
Призначення: тестування додатку в реальних умовах.
Особливості: швидко запускається, не вимагає встановлення додаткового ПЗ на
комп'ютер.
На емуляторі:
Призначення: тестування на різних віртуальних моделях пристроїв.

Особливості: вимагає встановлення важкого ПЗ (Android Studio/Xcode) та ре-
сурсів ПК.

Відмінності: тестування на реальному пристрої дозволяє відчути справжню
швидкість інтерфейсу, тоді як емулятор більше навантажує комп'ютер.

Висновки: навчився створювати та налаштовувати проєкт у середовищі Expo,
ознайомився зі структурою React Native застосунку та опанувати навички роботи
з базовими компонентами.
