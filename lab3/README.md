1. Інструкція запуску
В терміналі: npx create-expo-app@latest .

Встановити бібліотеки жестів та навігації:
npx expo install react-native-gesture-handler react-native-reanimated react-native-screens react-native-safe-area-context
npm install @react-navigation/native @react-navigation/bottom-tabs
Запустити проект командою: npx expo start
Сканувати QR-код через додаток Expo Go на телефоні.

2. Опис функціоналу
Додаток — це інтерактивний клікер з системою завдань.

Механіка жестів:
Tap: +1 бал (звичайний клік).
Double Tap: +2 бали (швидкий подвійний клік).
Long Press: +10 балів (утримання 3 секунди).
Pan: Перетягування об'єкта по всьому екрану.
Fling (Swipe): Швидкий помах вліво вправо дає +5 балів.
Pinch: Зміна розміру об'єкта двома пальцями.
Система завдань: Окремий екран зі списком місій. При виконанні завдання статус змінюється на ✅, а користувач отримує сповіщення (Alert).
Навігація: Нижнє меню (Tab Navigation) для швидкого перемикання між грою, завданнями та налаштуваннями.

3. Висновки
Під час виконання лабораторної роботи я опанував роботу з бібліотекою react-native-gesture-handler та навчився комбінувати різні типи жестів на одному об'єкті без конфліктів. Також реалізував систему відстеження стану (State) для створення динамічного списку завдань та інтегрував базову навігацію. Додаток працює плавно завдяки використанню useNativeDriver для анімацій.
