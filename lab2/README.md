Інструкція запуску:

Перейти в папку з проєктом: cd lab2
Встановити залежності: npm install
Запустити Expo: npx expo start
Для перегляду в браузері натиснути w, для запуску на телефоні відсканувати QR-код через за-стосунок Expo Go.

Опис функціоналу:

Стрічка новин (FlatList): Відображення 50 новин з картинками. Реалізовано "нескінченний скрол" (Infinite Scroll) та оновлення списку при потягуванні вниз (Pull-to-Refresh).
Деталі події: При натисканні на новину відкривається окремий екран з повним описом.
Список контактів (SectionList): Контакти розділені на групи Викладачі та Одногрупники.
Навігація: Використано Stack Navigator для переходів між екранами.

1.FlatList і ScrollView: ScrollView рендерить одразу всі елементи, а FlatList малює тільки ті що видно на екрані. Це набагато швидше для великих списків.
2.Віртуалізація: це керування пам'яттю. Коли ти гортаєш список елементи, що виходять за межі екрана видаляються з пам'яті а нові додаються.
3.Передача параметрів: здійснюється через функцію navigation.navigate. На іншому екрані ми дістаємо їх через route.params.
4.Вкладена навігація: це коли один навігатор знаходиться всередині іншого.
5.SectionList: застосовується, коли список треба розділити на групи з окремими заголовками.
